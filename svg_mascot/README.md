# NoteMage mascot — vector set

21 mascot poses as true-vector, transparent, sparkle-free artwork. Traced from the
hi-res originals in `brand_assets/Mascot/`, background removed, yellow sparkle stars
stripped (props, wand star, graduation tassel, "Zzz" and speech bubbles kept).

## Files

- `*.svg` — editable vector source (color paths, transparent background).
- `aftereffects/*.eps` — primary After Effects format.
- `aftereffects/*.ai` — PDF-compatible Illustrator file (same art, alternative to EPS).

After Effects cannot import SVG, so use the `.eps` or `.ai` files there.

## Import into After Effects as editable shape layers

1. File → Import → File… → pick a `.eps` (or `.ai`).
2. Drop the footage onto a composition.
3. Right-click the layer → **Create → Create Shapes from Vector Layer**.
4. The mascot becomes native AE shape layers — recolor, animate paths, puppet-pin.

Backgrounds are transparent; outlines are continuous solid paths.
